# Sainadh V - Machine Learning & Computer Vision Portfolio

A clean, minimalist personal engineering portfolio for **Sainadh V**, an M.Sc. Computer Science graduate specializing in **Computer Vision**, **Deep Learning**, and **AI Engineering**.

Built with **React**, **TypeScript**, **Vite**, and **Tailwind CSS**, featuring high contrast, fluid animations, verified YOLOv8n object detection benchmarks, layered project architecture, and bundled resume access.

## ?? Quick Start (Local Development)

```bash
# Clone the repository
git clone https://github.com/Frost730/Portfolio.git
cd Portfolio

# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```

---

## ?? Deploy to GitHub Pages (Automated via GitHub Actions)

1. Push this repository to GitHub:
   ```bash
   git add .
   git commit -m "Initial commit - Sainadh V portfolio"
   git branch -M main
   git remote add origin https://github.com/Frost730/Portfolio.git
   git push -u origin main
   ```
2. In your repository on GitHub, go to **Settings** -> **Pages**.
3. Under **Build and deployment** -> **Source**, select **GitHub Actions**.
4. That's it! GitHub Actions will automatically deploy to:
   ?? **https://frost730.github.io/Portfolio/**
